# Prompt provenance

These are the judge prompts in LURE Appendix A.1 and A.2, arXiv:2605.26438v1. The JSON keys use the literal underscores from the paper's TeX source: `evaluation_awareness` and `probability_eval`.

`p_eval_preamble.txt` contains the shared preamble and `{question}` insertion point. `p_eval_questions.json` contains the five question variants in order. `verbalized_awareness.txt` contains the verbalized-awareness judge prompt and its `{substrate}` insertion point.
